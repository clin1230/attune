# Saved idea: team-wide brand alignment

Deferred while we improve the single-designer workflow.

For projects with 2–3 contributors, check each selected design against the approved brand profile, compare contributions for inconsistent finishes/forms/colors, and track shared project decisions. Show the conflicting versions, evidence, and owner. Let the team resolve a finding, approve a contextual exception, or update the common rule. Review work, not individual designer scores. Allow divergent explorations until a shared direction is selected.

Example: a matte speaker and glossy dock use the same approved color but conflict with the project's matte-surface decision.

Potential value: catch inconsistencies before fabrication or presentation and retain approved knowledge for future projects. Validate with real teams before implementing. Requires shared storage, access control, contribution ownership, and version-aware review; current local project separation is not collaboration.
